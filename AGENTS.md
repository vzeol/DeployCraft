# DeployCraft — instructions for AI coding agents

This file is read by AI coding agents (Codex and others). The rules are the same for everyone and live in
[`CLAUDE.md`](CLAUDE.md) and [`CONTRIBUTING.md`](CONTRIBUTING.md): **read `CLAUDE.md` first and follow it in
full** (language, security, independent work, branches and PRs, architecture, quality, checks before each commit).

Reminders for an agent working alongside other AI sessions on this repository:

- **Your own clone.** Work in a separate clone of the repository, on your own branches. Never work on `main`.
- **Take a topic in its issue.** Only work on an issue that says it is taken by you; write "Taken by Codex" in
  it before starting. A topic taken by someone else is not touched.
- **Sign your work.** Every session uses the same GitHub account: end your issues, PRs and comments with
  "— Codex".
- **Independent work.** Never read, copy or describe the code, texts or files of another software.
- **Both languages.** Every new UI or service text goes in French and English (see `CLAUDE.md` § Language).
- **Merging.** Open the PR and stop there: it is reviewed by another session, tested (by the maintainer locally,
  or on the test domain for what depends on it, see `CLAUDE.md` § "Testing on a fleet"), then merged.
- **No secrets.** Never ask for, read or write a password, token or key.
- **The maintainer does not code** and speaks French: explain simply, in French, in the chat.
